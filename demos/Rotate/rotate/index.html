How to make real sensors work on your phone
The main button is labeled “Request Sensor Permissions”. Tap it (must be a user gesture).

Most common cause of “Sensors not available” or no prompt: loading the raw .html file directly (file://).
Browsers disable motion & orientation sensors on direct file access.

Quick fix: 
cd /path/to/this/folder
python3 -m http.server 8000
On your phone (same Wi-Fi) visit http://<your-mac-ip>:8000.
Find your IP with ipconfig getifaddr en0 (or en1, etc.).

Alternatives: npx serve . or php -S 0.0.0.0:8000.
Use Safari or Chrome on the phone. Tap the button and allow the “motion & orientation” prompt when it appears.

Tip: This implementation requests permission via both DeviceMotionEvent and DeviceOrientationEvent (following current real-world examples like accelerometerdemo.netlify.app), then listens for deviceorientation events. HTTPS helps on some iOS setups; same-network HTTP usually suffices for testing.
